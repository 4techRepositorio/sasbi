# UI

Biblioteca de componentes partilhados do `apps/web` (Angular). Objetivo: reutilizar layout e padrões visuais sem duplicar markup (Atomic Design / sem duplicação — ver [docs/FRONTEND_ARCHITECTURE.md](../docs/FRONTEND_ARCHITECTURE.md)).

Alinhamento com o produto: na superfície que o utilizador final vê, manter experiência **4Pro_BI** (ver [docs/ARCHITECTURE.md](../docs/ARCHITECTURE.md), secção sobre aceleradores e experiência unificada).

Stack alvo (ADR-002): evolução eventual para tokens/componentes consumíveis por React/Next; até lá, esta pasta serve o Angular actual.

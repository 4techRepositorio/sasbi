# Product — briefings de produto

Artefactos gerados pela skill **Product Designer** (`.cursor/skills/product-designer/SKILL.md`).

Cada iniciativa relevante deve ter um ficheiro `docs/product/<slug>.md` com discovery (problema, quem, valor, medição) e os entregáveis obrigatórios: casos de uso, user stories, personas, fluxos, KPIs, métricas, critérios de aceite, roadmap, backlog e priorização.

## Fluxo

1. Product Designer preenche checklist [`docs/CHECKLISTS/product-design-checklist.md`](../CHECKLISTS/product-design-checklist.md)
2. Planner cria / detalha ticket (`create-feature-plan`, `tickets/`)
3. Senior UX Designer (quando houver UI) → implementação

## Sistema (obrigatório)

- [ ] Não há ecrãs órfãos — todos pertencem a um fluxo e usam componentes
- [ ] Página Foundations com Design Tokens (Variables)
- [ ] Página Components com biblioteca reutilizável
- [ ] Auto Layout em frames e componentes relevantes
- [ ] Constraints definidos para comportamento responsivo
- [ ] Variants (e propriedades) para estados dos componentes base
- [ ] Prototype com starting point e happy path navegável
- [ ] Anotações de handoff (token ↔ `--da-*`, componente ↔ Angular / `.da-*`)

## Fluxo e estados

- [ ] Happy path ponta a ponta
- [ ] Loading
- [ ] Empty
- [ ] Error (com recuperação)
- [ ] Success
- [ ] Tenant actual visível em áreas admin / shell autenticado
- [ ] Status de ingestão legível quando o fluxo envolve upload/dados

## Alinhamento produto

- [ ] Consistente com `docs/wireframes/` (se existir folha de validação)
- [ ] Direção visual navy + magenta + azul (tokens do produto)
- [ ] Sem marcas / nomes de projetos externos na UI
- [ ] Link Figma registado em wireframe/ticket/referências quando for sign-off
